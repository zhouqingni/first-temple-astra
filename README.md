# 第一圣殿 · 摩利亚山空间图志

**双击 `开始探索.html`。这是完整离线版，可以单独复制给别人，不必安装软件、启动服务器或连接网络。** 若系统用文本编辑器打开 HTML，请在访达选择「打开方式 → Google Chrome」。`index.html` 是同一个项目的可编辑多文件入口。

## 先看约柜、幔子和人物

**去往 → 约柜与施恩座**：查看柜盖两头面对面、向施恩座低首的基路伯；与后方高十肘的大像不是同一对。点柜盖先读出25:20。柜身与施恩座长宽相同，四个柜脚环内各侧穿一根包金木杠。造型、杠长与方位均标作示意；柜内的石版不为展示而揭盖。

**去往 → 晨祭 · 院门守门人**：可以从阶下看两位守门人的全身。人物、会众行走共用真实铺石与台阶的表面高度，礼仪分区不决定站立高度。

**去往 → 至圣所幔子**：从外殿正面看整幅不透明的蓝、紫、朱红与细麻绣幔。点击帘子可读代下3:14。礼仪现场不会为观众把帘子拉开。

左上 **礼仪现场** 有两个不同日子的陈列：

- **住棚节晨祭：56 位人物。** 家庭中有男女、老人和孩子，聚在大院；非祭司的利未人奏乐或守门。祭司预备羊羔、细面与油酒，另有祭司在外殿灯旁，大祭司在祭司院，穿蓝色外袍、以弗得与十二石胸牌。至圣所无人。
- **赎罪日幔内焚香：13 位人物。** 十二名会众在殿外，殿内只有一名穿素细麻圣衣的大祭司，持香炉面向施恩座。是利16的一个时刻，不是完整仪式或献殿当天实录。人数、具体站位与衣饰造形是教学陈列选择。
- **无人的建筑教学**独立于礼仪场景，只有在这里人物撤去、幔子才收起，可以一直走到约柜旁。在礼仪场景中，行走随会众止于本陈列的祭司院入口；内部近景是教学观察镜头，不是会众可以进入。

## 怎样参观

- **俯瞰**：拖动环绕，滚轮缩放；右键拖动或按住 Shift 拖动平移。触屏双指缩放与平移。模型区的 ＋／－、滚轮与捏合只改变镜头；行走时改变视野，不会把人移入受限区域。桌面右栏独立显示经文，窄屏上下分区；经文栏自己滚动，无需使用 Chrome 的整页放大。
- **行走**：WASD 移动，拖动转头。键盘方向键也能使用。触屏用左侧摇杆移动，同时拖动画面转头。「去往」可从登山道起点、院内、殿廊、外殿、至圣所或旁屋南门开始。
- **建筑教学的连续路线**：登山道 → 大院东门 → 祭司院门 → 从侧面绕过铜坛 → 回中轴登殿基 → 双柱与廊子 → 外殿 → 从金坛旁通过 → 幔子与内门 → 至圣所。可从侧门单独进入旁屋，沿旋梯至第三层。
- **剖视**：移去遮挡内部的南墙、屋盖与前廊上部。切回行走后，墙体恢复完整。
- **查经**：悬停看相应和合本原文首节，点选器物或其标注展开逐节全文与复原取舍。图录可搜索器物、原文字词或经节。「定位观察」可跳至条目对应的视点。
- **量距**：点尺子后，依次点两个模型表面。结果是两点间的三维直线距离，显示肘与约合米数，可以跨视角选点。
- **画质**：「复原说明 → 本机画质」可选择省电。在不操作时，画面不持续重绘。

## 依据与边界

殿宇主要依据《列王纪上》5–8章、《历代志下》3–4章；礼仪对读《历代志下》8章、《出埃及记》28–30章、《利未记》16章、《民数记》18章和《申命记》等。共 38 个可查考对象，150 节不重复的中文和合本原文。详见 [复原依据](docs/复原依据.md)。殿身净长宽高按 60 × 20 × 30 肘，至圣所 20 肘见方；1 肘按 0.45 米作近似换算，现代观察者眼高 1.65 米。

初始高廊照和合本代下 3:4 的 120 肘显示。「复原说明」可切换至齐殿高的 30 肘**示意方案**；王上 6:3 没有记廊高。庭院尺度、第一圣殿时期的山形、某些器物造型、浮雕纹样等是补绘，不是考古实测。不是希律圣殿，亦不把现代参观通道视作古代准入礼制。

## 数据、源码与复验

- `docs/复原依据.md`：文字底本、参数表、每个对象的原文范围和补绘边界。
- `data/source/`：信望爱圣经工具的简体和合本电子文本逐章快照；`data/edition.js` 是按底本生成的离线索引。
- `src/`：山地、殿宇、铜作、金器、交互与行走逻辑。纹理以确定性程序在本地绘制。
- `vendor/`：Three.js 0.160.1 与 MIT 许可；无需联网取库或字体。
- `docs/预览/`：16 张实际浏览器画面，包括整幅幔子、守节家庭、大祭司礼服、晨祭预备、幔内焚香、约柜细部、独立经文栏、守门人脚下的台阶及触屏视图。
- 开发重建：`python3 tools/build_data.py` → `node tests/model.cjs` → `python3 tools/pack.py`。参观者不需要这些步骤。
- 浏览器复验：`python3 tests/browser_smoke.py`；测试单文件包用 `MORIAH_ENTRY=开始探索.html python3 tests/browser_smoke.py`。测试工具需要本机 Chrome 与 Python websockets，但离线成品不依赖 Python、Node 或测试工具。

已用本机 Intel Iris Graphics 540 的 Chrome 以本地文件方式验证。验证包括逐节数据对照、柜身与柜盖尺寸、四翼的遮掩与脸向、穿环的两根杠、两场陈列共 138 只脚与实际铺石、经文面板与模型缩放分离、两种礼仪人物的分区与互斥、会众止步、幔子遮蔽与点选、幔内只一人、建筑教学中山路至约柜的连续碰撞路线、南侧旋梯、实际鼠标命中、双点量距、键盘行走、前廊切换，以及 390 像素宽的触屏模拟（点选与摇杆）。测试中外网请求数为 0。未在实体手机或 Safari 上实测。

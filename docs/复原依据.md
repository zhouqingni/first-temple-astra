# 第一圣殿：建模底本与尺度

目的：让读者站在器物旁理解《和合本》的空间叙述，也能退远看殿在山上的位置。这是按文本搭建的可行走模型，不是已经考古测定的建筑原貌。时间选取所罗门建殿、约柜已安入内殿的状态；不引入第二圣殿、希律平台或现代建筑。

引文为中文和合本（1919，神版，简体电子文本），本地快照来自[信望爱圣经工具](https://bible.fhl.net/)，接口 `https://bible.fhl.net/json/qsb.php?version=unv&gb=1&qstr=王上6:1-38` 等。`data/source/` 保留逐章回应；以书卷、章、节匹配，不用讲解文字冒充经文。涉两种记数时并列，不强行调和。`tools/build_data.py` 由下表生成离线经文和参数。

### 约柜近景的尺度与辨识

- 出25:10、17分别给柜身与施恩座尺寸：以 **2.5 × 1.5 × 1.5 肘**做柜身，施恩座长宽用同一组数，不放大成出檐。柜身不复制王上6章的殿墙雕画；以包金柜面、金牙边与四脚的铸环表现出25:11–14。
- 出25:18–20的金像从施恩座两端立体锤出，模型让衣褶根部接在盖面上，头面相对且向下，四片翼面举起、向柜心上方伸展。经文没有要求这对小像的翅尖互碰；王上6:27彼此相接、两端触墙的是房间里的大像。
- 王上8:6–9的杠留在环内，东端伸入内殿门洞而不穿过闭幔；模型不为展示器物而抬高院坪或敞开施恩座。

## 礼仪陈列规则

1. 「住棚节 · 晨祭」与「赎罪日 · 幔内焚香」是两个独立教学时刻，不与献殿抬柜混为同一事件。它们共享建筑，不共享祭司班次与祭物。人物数量是为辨识场面选择的陈列人数，不是经文计数。
2. 晨祭：男女老少在大院以家庭成组，利未人守门、在院中奏乐，祭司在坛、盆、灯旁供职，大祭司着礼服在祭司院；至圣所内无真人。守节义务不等于妇女儿童禁止朝见。
3. 赎罪日焚香：幔子垂闭，只一位换穿素细麻圣衣的大祭司在内，外殿无人；不同时陈列晨祭队伍。院外人的安静姿态是示意。
4. 本陈列的「随会众行走」止于本场景的祭司院入口，不宣称第一圣殿所有年代、各种祭礼一概不许献祭者接近祭牲。殿内近景标作教学镜头，不模拟会众获得祭司身份。单列的「建筑教学」移去全部人物与礼仪，才收幔开放连续漫游。

## 场景与操作约定

采用自带渲染库的本地网页，不要求安装新软件、联网加载字体或运行云渲染。不是全景照片：鸟瞰、屋盖剖视、平视行走与查经共用同一几何场景。北朝地图上方，殿门朝东；建筑坐标以肘为唯一基础单位。山路、院与殿的台基之间以台阶连接；第一人称有地面高度、台阶、墙体与主要器物碰撞。旁屋与主殿分别从各自入口进入。保留两处记数差异的对读入口。交互卡分开列出原文与为可视化作的选择。

验收：校对快照逐节文字；核对殿身、内殿、廊、器物的几何尺寸与实例数；在真实浏览器走过连续入口、验证触屏点选、两种廊高与剖视切换，并由使用者目视确认。性能以本机实际测试条件为准。
